# 版本兼容与旧单元网升级协议

## 目标

Skill 大改时，避免批量改写旧迁移材料造成关系丢失、路径损坏或历史含义变化。

## 版本字段

新单元和项目索引必须记录：

```text
上下文单元协议版本
迁移器 skill 版本
```

协议版本描述单元结构；skill 版本描述生成或读取它的迁移器能力。

### 当前执行版本优先级

每次调用先读取 [current-version.md](current-version.md)。

```text
当前磁盘版本声明和当前磁盘 SKILL.md
> 当前线程缓存或记住的旧 skill 规则
> 项目索引、单元和旧迁移文档中的历史生成版本
```

- 项目材料中的 `迁移器 skill 版本` 只说明该材料由哪个版本生成，不是当前执行版本。
- 当前线程曾使用旧版规则时，用户再次调用 skill 不表示旧规则可以继续复用；版本自检不一致时必须重新加载当前磁盘规则。
- 若无法重新加载或确认当前规则版本，停止执行并明确报告，不静默回退旧格式。

### Skill 2.1 继承语义

- Skill `2.1` 起，通过迁移器实际读取上下文单元正文统一视为运行时继承，当前对话蒸馏时写入 `继承自`。
- Skill `2.0` 或更早单元中的 `参考了`、`继承自` 按旧文档原义读取，不批量改写或重新解释。
- 新旧单元共同使用时，保留旧链接原样；新创建单元按当前规则记录它实际继承的旧单元。

### Skill 2.2 版本自检

- 每次调用只先读取轻量 `current-version.md`，避免无条件重复加载完整 skill。
- 当前版本与线程缓存不一致时，再重新读取完整 `SKILL.md` 和本次需要的引用文件。
- 旧索引和旧单元仍保持原样，不因为当前规则升级而批量修改。

### Skill 2.3 严格批准闸门

- 只有当前有效三档预检之后的明确批准才能授权读取正文。
- 重复任务、重新调用 skill、从零开始或忽略此前内容会作废旧预检，不得解释为批准。
- 旧版单清单不能在当前版本下直接批准或执行，必须重新生成三档预检。

### Skill 2.4 宿主工作区所有权闸门

- 新单元默认由当前对话宿主工作区拥有，不由继承来源项目拥有。
- 蒸馏前必须预览并校验写入目标；未经用户明确指定，不得写入宿主工作区之外。
- 跨项目继承只建立链接并更新宿主项目索引，不修改来源项目索引来登记新单元。
- 旧单元若因错误推断被存入来源项目，可保留稳定单元标识执行路径、所有权、项目内编号和索引修正，并记录修正原因。

## 兼容原则

- 旧单元和旧迁移文档默认保持原样，不自动批量重写。
- 新版 skill 优先兼容读取旧格式，再使用新版格式创建新单元。
- 旧材料是历史证据，兼容映射只是读取入口。
- 不可逆的大规模转换必须先获得用户确认。
- 新版不理解旧字段时，标记未知，不猜测含义。
- 很晚才发现旧单元之间存在未记录关系时，创建新的关系补录单元，不回头改写旧单元。

## 旧链式迁移文档

将旧版“完整继承链迁移文档”登记为虚拟旧单元：

```markdown
| 虚拟单元标识 | 旧迁移文档绝对路径 | 识别格式 | 一句话摘要 |
```

规则：

- 虚拟单元标识只存在于新索引中，不要求修改旧文件。
- 新单元可以使用 `参考了`、`继承自`、`汇总了` 等链接指向虚拟旧单元。
- 需要深入历史时再读取旧文件中的继承链；默认不把整条旧链复制进新单元图。

## 新版 skill 读取旧单元网

1. 检查项目索引和目标单元的协议版本。
2. 当前版本可直接理解时正常读取。
3. 只能部分理解时，建立轻量兼容映射并标记未识别字段。
4. 当前任务需要旧内容时按需读取；无关旧单元不转换。
5. 发现旧格式循环、重复路径或断链时记录，不修改原件。

## 大版本升级

当新版结构与旧结构差异很大：

1. 保留旧目录和旧文件。
2. 在新版索引中记录旧格式入口和协议版本。
3. 创建一个新的“结构升级说明单元”，记录：
   - 旧版本；
   - 新版本；
   - 兼容映射规则；
   - 已知无法自动转换的内容；
   - 用户确认过的迁移范围。
4. 仅为当前真正需要使用的旧材料建立虚拟单元或汇总单元。
5. 验证新索引可找到旧入口后，再继续使用新版格式。

不要一次性重写整个旧单元网。

## 索引损坏或丢失

单元正文是主要事实来源，索引是可重建的检索层。

重建时：

- 扫描项目 `对话上下文迁移` 文件夹中的单元文档；
- 读取单元标识、协议版本、对话标识、直接链接和来源文件记录；
- 重新生成目录和反向索引；
- 对旧迁移文档建立虚拟旧单元入口；
- 不修改原单元正文。

## 兼容质量检查

- 是否识别协议版本；
- 是否保留旧文件原样；
- 是否避免无需求的全量转换；
- 是否为旧格式保留可检索入口；
- 是否记录无法理解或无法转换的字段；
- 是否在不可逆操作前获得用户确认；
- 是否能从索引回到原始历史证据。
